STEP 3.1 — Jetson Identity & Trust Setup (IN SHORT)

# What it does
- Binds this Jetson device to:
- a specific backend
- a specific device identity
- a valid security token
# What you did
- Set DEVICE_CODE → identifies the Jetson
- Set EDGE_TOKEN → authenticates the Jetson
- Set BACKEND_API_URL → tells Jetson where backend lives
- Verified auth using /edge/ping
# Why it matters
- Without this, Jetson is:
    - unauthenticated
    - untrusted
    - not allowed to fetch config or send events

# In one line:  STEP 3.1 establishes identity and trust between Jetson and backend.
